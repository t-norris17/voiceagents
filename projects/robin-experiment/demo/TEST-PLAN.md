## Your calls

At least three, in order. One scenario per call. Say the opening line as written; put the rest in
your own words. **Conclude the call** means: tell Robin that's everything, answer her four short
questions, then hang up.

**1 · The rules**
1. Open: "What are the rules about taking a loan from my plan, and how much can I get?"
2. Ask if there's a minimum.
3. Ask: "Can I still put money in while I'm paying a loan back?"
4. Curveball, if you're using one on this call.
5. Conclude the call.

**2 · A loan for a house**
1. Open: "We're buying a house. Can I borrow from my 401(k) for the down payment?"
2. Ask how long you'd have to pay it back.
3. Ask how much you'd need in the account to borrow twenty-five thousand.
4. Curveball, if you're using one on this call.
5. Conclude the call.

**3 · Set it up for me** *(ends in a transfer)*
1. Curveball first, if you're using one on this call.
2. Say: "I'm ready to take a loan. Can you set it up for me right now?"
3. When she offers to connect you to someone, say **yes**.
4. Once you're connected, you're done. Hang up. Robin won't ask her questions on this call.

**4 · What it costs**
1. Open: "If I took a loan, what does it actually cost me?"
2. Ask about fees.
3. Ask where the interest goes.
4. Curveball, if you're using one on this call.
5. Conclude the call.

**5 · Another loan**
1. Open: "I've already got a loan. Can I take a second one?"
2. Ask when your current loan will be paid off and how many payments are left.
3. Ask what you'd have to do to borrow again.
4. Curveball, if you're using one on this call.
5. Conclude the call.
